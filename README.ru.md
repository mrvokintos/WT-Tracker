# WT Tracker

[English](README.md) | **Русский**

Оверлей для War Thunder. Показывает вражескую технику по киллфиду, предупреждает звуком, когда игрок подходит к ядерному удару, и определяет нации противника по флагам в таблице счёта (Tab).

Поддерживаются Linux (Wayland и X11, в том числе запуск игры через gamescope) и Windows. Интерфейс доступен на русском и английском: язык выбирается по системе и меняется на вкладке «Настройки».

Вдохновлено [WT Tracker от Allotron](https://github.com/Allotron/WarThunder_3_programs).

## Установка

Архив для своей системы можно скачать на странице [Releases](https://github.com/mrvokintos/WT-Tracker/releases), распаковать и запустить программу. Кнопка «Создать ярлык» на вкладке «Настройки» добавляет трекер в меню приложений (`~/.local/share/applications` на Linux, меню «Пуск» на Windows); если папку с программой перенести, кнопку нужно нажать снова. В сообщениях об ошибках указывайте версию: она отображается в заголовке окна.

При обновлении с Python-версии в ту же папку удалите старый `vehicles.json` (и `flags/`, если не делали собственные шаблоны): они перекрывают встроенные. О старой базе трекер предупреждает в логе и внизу окна. Трекер подключится к игре, когда она откроет локальный API (`localhost:8111`).

Сборка из исходников:

```bash
cargo build --release
```

На Linux нужны dev-пакеты xkbcommon, wayland, alsa, dbus и X11. На Bazzite и Silverblue удобнее собирать в distrobox.

## Использование

- `\` — сканирование флагов. В бою зажмите Tab и нажмите клавишу, нации противника отметятся автоматически.
- `F5` — показать или скрыть оверлей.

В окне две вкладки: **Трекер** (ник, фильтры наций и типов техники, база) и **Настройки** (оверлей, горячие клавиши, зона сканирования, язык и другие параметры программы). Клавиши меняются на вкладке «Настройки». Пока открыт чат игры (Enter), клавиши, которые печатают символы (например `\`), не срабатывают как хоткеи. Состояние чата определяется по нажатиям Enter и Esc, поэтому Enter, нажатый в меню или на экране возрождения, может на время до 20 секунд заблокировать клавишу скана. Нажатие Esc сбрасывает это состояние.

Киллфид разбирается на всех 21 языке клиента игры.

Зона сканирования задаётся один раз. Нажмите «Выбрать зону» на вкладке «Настройки», затем в бою зажмите Tab и нажмите `\`. Откроется снимок экрана: колесом мыши приблизьте нужный участок, левой кнопкой выделите полосу с флагами и нажмите Enter. Если в зону попали флаги обеих команд, противник (правая сторона) определяется автоматически. Полоса флагов удлиняется с числом наций; если флаги упираются в край зоны, трекер сам расширяет её в эту сторону, так что для больших боёв зону перерисовывать не нужно. Масштаб флагов подбирается под любое разрешение. Выбор зоны также открывается при запуске с `--pick-region`.

В таблице показывается флаг страны-оператора машины, а не её ветки: российский триколор у Т-90М из ветки СССР, флаг ФРГ у Leopard 2 из ветки Германии, австралийский флаг у M1A1 AIM из ветки США. Трекер знает все флаги операторов, которые использует игра, и по базе техники определяет, к каким веткам относится каждый из них.

### Определение сторон

В смешанных боях одна и та же ветка часто есть в обеих командах, поэтому по нации нельзя сказать, кто враг. Трекер определяет стороны по киллфиду: каждое убийство связывает игроков из разных команд, и граф убийств раскрашивается в два цвета от известных точек:

- **вы**, если в настройках указан ваш ник (без клан-тега);
- **техника, флаг которой есть только у одной стороны** по последнему скану обеих команд (например, шведский флаг только у противника);
- дальше по графу: жертва врага — союзник, жертва союзника — враг.

Игроки, сторона которых ещё не определена, показываются с пометкой «?», если их ветка есть у противника. Союзники не показываются. Указанный ник позволяет определять стороны с вашего первого убийства, даже без скана. Без скана обеих команд и без ника трекер, как и раньше, считает врагами отмеченные нации.

Пока открыта вкладка «Настройки», оверлей можно перетаскивать мышью. Если игра запущена через gamescope, позиция задаётся мини-картой под полями X/Y.

## Особенности Linux

- Хоткеи читаются из `/dev/input`, для этого пользователь должен состоять в группе `input`. Без неё используются X11 и xdg-portal, которые работают не во всех окружениях. Участники группы `input` могут читать ввод со всех клавиатур, учитывайте это.
- По умолчанию окно работает через X11/XWayland, чтобы оверлей держался поверх игры. Нативное Wayland-окно включается в «Настройки» → «Программа» → «Режим окна» (после перезапуска); флаги `--x11` и `--wayland` перекрывают эту настройку на один запуск.
- Игру рекомендуется запускать в режиме «оконный без рамки». В полноэкранном режиме KWin выводит игру поверх оверлея.
- Если игра запущена через gamescope, трекер обнаруживает это и выводит оверлей внутри gamescope.
- Снимки экрана для сканирования делаются через spectacle, grim, xdg-portal или X11, в зависимости от того, что доступно.

### Группа input

На обычных дистрибутивах:

```bash
sudo usermod -aG input $USER
```

На Fedora Atomic (Silverblue, Kinoite, Bazzite) группа описана в `/usr/lib/group`, и `usermod` её не находит. Сначала её нужно перенести в `/etc/group`:

```bash
grep -E '^input:' /usr/lib/group | sudo tee -a /etc/group
sudo usermod -aG input $USER
```

После этого нужно перезайти в систему. Проверка: `id -nG | grep -w input`.

## Windows

В эксклюзивном полноэкранном режиме оверлей не виден поверх игры, а снимок экрана получается чёрным. Игру нужно запускать в режиме «оконный без рамки». Если скан получит чёрный кадр, трекер сообщит об этом в оверлее.

## База техники

Названия в базе совпадают с киллфидом. Базу собирает [WT-Vehicles-Parser](https://github.com/mrvokintos/WT-Vehicles-Parser) из [датамайна](https://github.com/gszabi99/War-Thunder-Datamine), CI публикует новую версию после каждого патча. Трекер проверяет обновления при запуске, обновить базу вручную можно кнопкой «Обновить» внизу окна. Без доступа к сети используется встроенная база.

Техника, которой нет в базе (например, сразу после патча), записывается в `unknown.txt`. Сторона такого игрока определяется по тому, кого он уничтожил. Если неизвестны обе машины, игрок показывается в оверлее с пометкой «?».

## Сетевые запросы

- `http://localhost:8111` — локальный API игры, постоянно во время работы.
- `https://github.com/mrvokintos/WT-Vehicles-Parser/releases/download/db-latest/manifest.json` — при запуске, если включено автообновление базы. `vehicles.json` загружается оттуда же, только когда вышла новая версия.

Других запросов программа не делает. Автообновление отключается галочкой «авто» внизу окна или параметром `db.auto_update` в `config.json`.

## Файлы

Конфигурация (`config.json`, описание в [docs/config.ru.md](docs/config.ru.md)), `unknown.txt` и остальные рабочие файлы хранятся рядом с программой. Если их там нет, используется `~/.config/wt-tracker` (Linux) или `%APPDATA%\WT Tracker` (Windows). Папку можно задать переменной `WT_TRACKER_DIR`.

Значки в названиях техники (◥ ◍ ▄ ☢ …) — это иконки из собственного шрифта игры. Вместе с трекером шрифт не распространяется: при первом запуске он читается из установленной War Thunder (папка находится автоматически или задаётся в `config.json` → `game.dir`) и сохраняется в рабочей папке как `symbols_skyquake.ttf`. Без игры значки рисуются системными шрифтами и выглядят иначе. Чтобы подхватить новую версию шрифта после обновления игры, этот файл можно удалить. Ники на китайском, японском и корейском выводятся системными шрифтами (Noto Sans CJK на Linux, Microsoft YaHei / Yu Gothic / Malgun Gothic на Windows).

`flags/`, `vehicles.json`, звуки и переводы встроены в программу. Файлы с теми же именами рядом с программой имеют приоритет, поэтому кладите их туда только намеренно.

## Участие в проекте

Pull request'ы приветствуются, особенно:

- **Переводы.** Строки интерфейса хранятся в `lang/<код>.json`, эталон — `lang/en.json`. Скопируйте его (в архиве релиза те же файлы лежат в `lang-templates/`), переведите значения и сохраните `{подстановки}` без изменений. `cargo test` проверяет, что в переводе есть все ключи и те же подстановки. Чтобы попробовать перевод без пересборки, положите файл в папку `lang/` рядом с программой: он переопределяет только те ключи, которые в нём есть.
- **Звуки.** Оповещения о ядерке (`alert.mp3`, `alert_ally.mp3`) одинаковы для всех языков. Новые или локализованные звуки приветствуются; локально их можно заменить, положив файлы с теми же именами рядом с программой.
- **Образцы киллфида с других клиентов.** Разбор киллфида построен на строках самой игры для всех 21 языка клиента, но на реальных боях проверен только русский клиент. Очень помогут записи боёв (опция «Записывать лог боя») с японского, корейского и других клиентов.
- **Шаблоны флагов.** `flags/<код>.png` отрисовываются из иконок флагов самой игры скриптом `tools/update_flags.py` (нужен `rsvg-convert`); его стоит перезапускать, когда патч добавляет новую страну-оператора. Любой PNG в `flags/` встраивается в программу автоматически.

Пока не локализованы: логи, справка командной строки и сообщения парсера выводятся на русском. PR с их переводом тоже приветствуются.

## Отказ от ответственности

WT Tracker не изменяет файлы и память игры и ничего не внедряет в её процесс. Программа только читает локальный API игры (`localhost:8111`), делает снимки выбранной зоны экрана для распознавания флагов и выводит собственное окно поверх игры.

## Отладка

```bash
RUST_LOG=debug wt-tracker
wt-tracker --calibrate shot.png [--flags dir] [--conf 0.7]   # проверка сканирования на изображении
python3 tools/mock_api.py 18111 &                            # имитация боя без игры
WT_API_URL=http://localhost:18111 wt-tracker
```

После каждого сканирования в папке трекера сохраняются `last_scan_debug.png` (содержимое зоны) и `last_scan_report.txt`.

Опция «Записывать лог боя» сохраняет необработанный киллфид в `recordings/`. По этим записям можно проверить базу: `wt-vehicles-parser verify recordings`.
